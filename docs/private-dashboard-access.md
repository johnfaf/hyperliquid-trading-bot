# Private dashboard connection

The VPS dashboard is bound to its own loopback interface. On Windows, `http://127.0.0.1:18080/` works only while the preconfigured `hl-dashboard` SSH port forward is connected. A connection-refused page means the local listener is absent; the dashboard login page means the tunnel is up and app authentication is required. The dashboard session expires independently of SSH.

`deploy/dashboard/Install-PrivateDashboardTunnel.ps1` installs a per-user Windows scheduled task that starts at interactive login and reconnects the existing restricted SSH profile after disconnects. A two-minute recovery trigger restarts a stopped watcher while the user is signed in; it does not start another copy while one is running. It neither provisions credentials nor grants administrative access. The watcher uses the original host-key verification, local binding, and restricted key; it leaves any existing listener alone. Logs go to `%LOCALAPPDATA%\HyperliquidDashboard\tunnel.log`. The task runs without elevation and keeps no token or wallet key. It is separate from the public data collectors and the trading service.

To remove it, stop and unregister the `Hyperliquid Private Dashboard Tunnel` task using Task Scheduler. Stopping that task does not stop a tunnel you previously launched manually. Do not make VPS port 8080 public or disable dashboard login to solve a local connection issue.
