# ─── LSTM Alpha Agent + RL Position Sizer ─────────────────────
# PyTorch for LSTM direction forecaster and DQN sizer
# (graceful fallback to rule-based/Kelly if not installed).
# CPU-only build keeps the image small (~200MB vs ~2GB for CUDA).
#
# Why the explicit +cpu pin instead of `torch>=2.1.0`?
# pip-compile picks the highest version available across all indices,
# and the default PyPI torch (e.g. 2.12.0) is "higher" than any +cpu
# variant on PyTorch's CPU index — so `--extra-index-url` alone gets
# overridden.  Pin to a known CPU wheel to force the resolver's hand.
# Upgrade by editing this version + re-running the regen workflow.
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.6.0+cpu
